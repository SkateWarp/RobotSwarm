## Cooperative Object Transportation using Gibbs Random Fields

The ROS-independent GRF cooperative-transport kernel in this repository is an
independent implementation of mathematical and algorithmic concepts described
in:

> Paulo Rezeck, Renato M. Assunção, and Luiz Chaimowicz, “Cooperative Object
> Transportation using Gibbs Random Fields,” 2021 IEEE/RSJ International
> Conference on Intelligent Robots and Systems (IROS), pp. 9131-9138.
> DOI: 10.1109/IROS51168.2021.9635928.

Reference materials:

- Paper: https://arxiv.org/abs/2109.13734
